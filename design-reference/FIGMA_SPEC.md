## 素材和实施范围

- 左列封面为 `public/assets/images/imgWebp1.png`，右列机械手封面为 `public/assets/illustrations/imgWebp2.png`。两者文件格式均为 PNG。复用对应的 Figma 遮罩及原始图像变换。
- 医生卡、视频作者头像的原图与遮罩按 [素材索引](./assets.json) 中的 `imageFillNodeIds` / `uses` 对齐。SVG 维持原始 viewBox、尺寸和路径。页面级 SVG 是画板自身的导出预设，画板视觉基准用仓库中指定的 PNG。
- 文件中的确认范围为这一张静态设计稿。响应式变体、搜索结果、播放、其他导航目的地和后端数据行为均需独立依据。
- 还原时在浏览器以 375 CSS px 宽、DPR 1 捕获画板对应内容，逐区核对裁切、覆盖、文字换行、图层顺序和对齐。底栏在这个基准画板的位置为 y=1481。
